### 1.2 DBI_22（中国膳食平衡指数2022修订版）

- **名称**：中国膳食平衡指数的修订：DBI_22（Diet Balance Index 2022）
- **原始论文（已核实）**：何宇纳、叶晨、房玥晖、连怡遥. 中国膳食平衡指数的修订：DBI_22[J]. 营养学报, 2024, 46(3): 209-214.
  - 早期奠基论文：何宇纳, 翟凤英, 葛可佑. 建立中国膳食平衡指数[J]. 卫生研究, 2005, 34(2): 208-211.
- **官方URL**：
  - 中文原刊需知网/维普/营养学报官网获取全文，**未直接公开免费PDF（待确认具体数据库订阅）**
  - 英文验证论文（开放获取，可核对评分口径）：
    - Frontiers in Nutrition 2025（肌少症关联）：`https://www.frontiersin.org/journals/nutrition/articles/10.3389/fnut.2025.1562362/full`
    - Frontiers in Nutrition 2026（代谢综合征，含LBS/HBS/DQD计算表）：`https://www.frontiersin.org/journals/nutrition/articles/10.3389/fnut.2026.1858120/full`
- **评分细则（据英文开放论文核对）**：
  - 各食物组按「与推荐摄入量比较」打分：达标=0；摄入不足为负分（约−12~−1）；摄入过量为正分（约+1~+12）
  - **负端分LBS**：所有负分项绝对值之和，反映摄入不足程度（约0~60）
  - **正端分HBS**：所有正分项之和，反映摄入过量程度
  - **膳食质量距DQD**：综合LBS与HBS，反映总体膳食偏离推荐的距离
  - 评分条目覆盖：谷类、蔬菜、水果、奶类、大豆、动物性食物、高能食物（油/酒/添加糖）、调味品（盐）、食物多样性、饮水
- **开源实现**：未检索到专门针对DBI_22的成熟Python实现。候选R包`dietaryindex`（`https://github.com/jamesjiadazhan/dietaryindex`）是否内置DBI-22公式待确认。建议按论文规则自行用Python实现，工作量可控。
- **项目用途**：把用户一日膳食结构化后自动算出LBS/HBS/DQD，作为「膳食质量评分」在前端可视化
- **难度/优先级**：中 / **备选**（核心规则可自行实现，原刊用于出处引用）

- **难度/优先级**：**必备**。ViT-S仅85MB，学生笔记本CPU也可推理

**两周原型建议**：选ViT-S/14（21M），冻结骨干只训练`nn.Linear(384→num_classes)`，30分钟–2小时即可在小数据集上收敛。不要从头训练ViT-g/14。

### 8.1 互联网应用适老化通用设计规范（量化要求）

- **名称**：
  - 工信部《关于进一步抓好互联网应用适老化及无障碍改造专项行动实施工作的通知》（2021），附件含《互联网网站适老化通用设计规范》与《移动互联网应用（APP）适老化通用设计规范》
  - 配套国家标准：**GB/T 37668《信息技术 互联网内容无障碍可访问性技术要求与测试方法》**

- **可直接执行的量化要求（已逐字核对）：**

| 维度 | 量化要求 |
|---|---|
| 最小字号 | 移动网页至少提供一种**≥18 dp/pt**大字体；APP主要功能文字最大字体**≥30 dp/pt**；适老版界面主要文字**≥18 dp/pt**；建议无衬线字体 |
| 行/段间距 | 段落内行距**≥1.3倍**；段落间距**≥行距×1.3** |
| 颜色对比度 | 文本/图标对比度**≥4.5:1**（字号>18dp/pt时**≥3:1**）；颜色不得作为唯一信息传达手段 |
| 点击区域 | 适老版主要组件**≥60×60 dp/pt**；其他页面主要组件**≥44×44 dp/pt** |
| 浮窗关闭 | 关闭按钮仅放左上/右上/正底部，最小点击区域**≥44×44 dp/pt** |
| 手势 | 避免需**3个及以上手指**的复杂手势；操作需有反馈 |
| 操作时间 | 非必要不设限时，操作完成前界面不跳转/变化 |
| 语音播报 | 各组件/正文提供在线语音阅读，可开关、可被读屏/辅助技术控制；非文本控件需语音说明用途 |
| 验证码 | 提供文字或语音等多感官替代形式 |
| 导航/层级 | 界面扁平化、信息层次清晰；提供整体页面结构语音引导；支持键盘/特大鼠标/语音等多种操作方式 |
| 响应时间 | 规范强调「即时反馈/焦点明显状态提示」，未给统一毫秒数（建议参考WCAG 2秒响应原则） |

- **获取方式**：政府网/工信部官网公开免费直读
- **许可**：政府规范性文件，公开引用
- **项目用途**：前端适老化 UI 设计约束——大字号、高对比、大按钮、少层级、语音朗读开关
- **难度/优先级**：低 / **必备**
