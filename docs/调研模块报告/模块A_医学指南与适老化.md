### 2. DBI_22（中国膳食平衡指数 2022 修订版）

- **名称**：中国膳食平衡指数的修订：DBI_22（Diet Balance Index 2022）。
- **原始论文出处（已核实）**：何宇纳、叶晨、房玥晖、连怡遥. **中国膳食平衡指数的修订：DBI_22[J]. 营养学报, 2024, 46(3): 209-214.**（被多篇 CHNS/Frontiers 论文引用佐证，见维普引文、中国农村观察参考文献列表。）
  - 早期奠基论文：何宇纳, 翟凤英, 葛可佑. 建立中国膳食平衡指数[J]. 卫生研究, 2005, 34(2): 208-211.
- **官方/权威 URL**：
  - 原始中文论文《营养学报》2024,46(3)：需经知网/维普/营养学报官网获取全文，**未直接公开免费 PDF（待确认具体数据库订阅）**。
  - 英文验证/应用论文（开放获取，可核对评分口径）：
    - Frontiers in Nutrition, 2025（肌少症关联，含 DBI-22 评分范围说明）：`https://www.frontiersin.org/journals/nutrition/articles/10.3389/fnut.2025.1562362/full` —— 已检索到。
    - Frontiers in Nutrition, 2026（代谢综合征，含 LBS/HBS/DQD 计算表）：`https://www.frontiersin.org/journals/nutrition/articles/10.3389/fnut.2026.1858120/full` —— 已检索到。
- **评分细则（据英文开放论文核对）**：
  - 各食物组按「与推荐摄入量比较」打分：达标 = 0；摄入不足为负分（约 −12 ~ −1）；摄入过量为正分（约 +1 ~ +12）。
  - **负端分 LBS（Low Bound Score）**：所有负分项绝对值之和，反映摄入不足程度（约 0~60）。
  - **正端分 HBS（High Bound Score）**：所有正分项之和，反映摄入过量程度。
  - **膳食质量距 DQD（Diet Quality Distance）**：综合 LBS 与 HBS，反映总体膳食偏离推荐的距离。
  - 评分条目覆盖：谷类、蔬菜、水果、奶类、大豆、动物性食物（畜禽鱼蛋）、高能食物（油/酒/添加糖）、调味品（盐）、食物多样性、饮水。
- **开源实现**：
  - 未检索到专门针对「DBI_22」的成熟 Python 官方实现。
  - 候选：R 包 `dietaryindex`（GitHub：`https://github.com/jamesjiadazhan/dietaryindex`，论文 PMC11600030）——通用膳食指数 R 包，**是否已内置 DBI-22 公式待确认**，需读其 README/源码核实。
  - 建议：评分表已在论文中明确，本项目可按上述规则自行用 Python 实现 LBS/HBS/DQD，工作量可控。
- **获取方式**：中文原刊需期刊数据库/图书馆；英文应用论文开放获取。
- **规模与格式**：原刊论文约 6 页（PDF）；英文应用文约 15~20 页。
- **许可**：学术论文（版权归期刊/作者）；英文 OA 论文可免费阅读。
- **本项目用途**：把用户一日膳食结构化后，自动算出 LBS/HBS/DQD，作为「膳食质量评分」在 Streamlit 端可视化展示，补充单一盐/糖指标之外的整体均衡度评价。
- **获取难度/优先级**：中 / **备选**（核心规则可自行实现，原刊用于出处引用）。

- **本项目用途**：AI 识别食物后，按其 GI 与碳水含量计算单份 GL，实现「低 GL 主食优先推荐、高 GL 限量」的规则引擎核心逻辑。
